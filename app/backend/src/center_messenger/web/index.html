Не подключено

Отдельный канал штатной интеграции AlfaCRM. Сервер откроет её страницы MAX во временном браузере и будет хранить зашифрованную веб-сессию. Пароль нужен только для входа и не сохраняется. Если AlfaCRM запросит код из письма, введите его здесь.

Для этого входа используется почта и пароль сотрудника AlfaCRM. API-ключи v2api и X-APP-KEY сюда не вводятся.

MAX · боты

Личные диалоги с ботом

Это отдельное подключение MAX Bot API по токену бота. Оно не связано с веб-сессией штатного MAX AlfaCRM ниже и не меняет её настройки.

Добавить MAX-бота
Сервер использует официальный MAX Bot API; настройки штатного MAX AlfaCRM в соседнем блоке остаются независимыми.

Не добавляйте один и тот же токен повторно: используйте уже созданную карточку бота.
