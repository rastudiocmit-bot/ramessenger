      Как настроить голос и ИИ — по шагам
      1. Подключите сервис
      Раскройте «Ключ и настройки подключения», сохраните ключ и проверьте нужную возможность. Проверка текста не означает, что распознавание и синтез уже проверены.
      2. Назначьте действие
      В блоке «Какой сервис использовать» выберите распознавание и синтез, затем нажмите «Сохранить маршруты». Проверенный ключ сам по себе не меняет выбор сервиса.
      3. Проверьте результат
      Для синтеза выберите голос, сохраните маршруты и создайте тестовое аудио. Инструкция для обработки распознанного текста задаётся во вкладке «AI-агенты».
      Обычный API или Token Plan?
      У MiMo это два независимых подключения с разными ключами. Выберите нужное явно: при ошибке автоматического перехода на другой платный шлюз нет.

      Какой сервис использовать

      Назначьте распознавание и синтез. Для русского выберите Яндекс или MiMo; для обработки расшифровки DeepSeek настройте агента во вкладке «AI-агенты».

      Назначение действий

      Обработка текста: шлюз, модель и инструкция выбираются для каждого агента в отдельной вкладке «AI-агенты».

      Русский в MiMo передаётся в режиме auto: в документации MiMo для ASR перечислены только китайский и английский, поэтому качество русского не подтверждено. DeepSeek обрабатывает уже распознанный текст через AI-агента, аудио его API не принимает. При ошибке другой платный шлюз автоматически не включается.

      Яндекс: русские голоса и John для английского. MiMo: английские и китайские голоса. Сообщения клиентам автоматически не отправляются.

      AI-агенты и задачи

      Настройте, как модель обрабатывает текст: выберите задачу, сервис и инструкцию, затем проверьте результат.

      Как собрать полезного агента
      Сначала подключите сервис
      Во вкладке «ИИ-шлюзы» сохраните ключ и проверьте обработку текста. Затем создайте агента и выберите тот же сервис.
      Одна задача — понятная инструкция
      Например: «Убери слова-паразиты, сохрани смысл, верни только готовый текст». Для разных задач можно создать отдельные инструкции.
      Проверьте перед сохранением
      Введите пример в поле «Проверить на фразе» и сравните результат с исходным текстом. Эта проверка не отправляет сообщение клиенту.
      Что значит «Основной для этой задачи»?
      Это агент, который будет выбираться для данной задачи по умолчанию. Флажок «Включён» разрешает его использование.
