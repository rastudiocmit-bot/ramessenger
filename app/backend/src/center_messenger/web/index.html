      Личные диалоги с ботом

      Это отдельное подключение MAX Bot API по токену бота. Оно не связано с веб-сессией штатного MAX AlfaCRM выше и не меняет её настройки.

      Добавить MAX-бота
      Сервер использует официальный MAX Bot API; настройки штатного MAX AlfaCRM в соседнем блоке остаются независимыми.

      Не добавляйте один и тот же токен повторно: используйте уже созданную карточку бота.
