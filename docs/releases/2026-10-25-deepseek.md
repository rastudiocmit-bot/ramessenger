# DeepSeek для AI-агентов (миграция `0014_ai_deepseek`)

- Подключения → Настройки сервисов → «Голос и AI» → карточка **DeepSeek**:
  API-ключ (`sk-…`, platform.deepseek.com → API keys), «Проверить связь»,
  «Удалить ключ». Ключ запечатан в `ConnectorVault` отдельно от ключа Yandex
  (purpose `deepseek-ai`) и в ответах API не возвращается.
- В форме агента модели сгруппированы по поставщику: Yandex Cloud
  (YandexGPT Pro 5.1, Alice AI LLM, YandexGPT Pro 5) и DeepSeek
  (`deepseek-flash` — V4.1 Flash, `deepseek-v4-pro` — V4 Pro). Режим
  рассуждений выключен (`thinking: disabled`), чтобы ответ приходил быстро.
- Речь по-прежнему распознаёт Yandex SpeechKit; голосовой ввод требует ключ
  Yandex. Если у агента модель DeepSeek, а ключа DeepSeek нет или DeepSeek
  не ответил — в поле вставляется распознанный текст с предупреждением.
- Стоимость считается в рублях по пиковому тарифу DeepSeek и курсу 90 ₽/$
  и входит в общий месячный лимит.
- Текст для обработки уходит на серверы DeepSeek в Китае; аудио — нет.

Миграция аддитивная (четыре столбца в `ai_settings`), автовыкладка применяет
её сама; откат — `downgrade` к `0013_ai_voice`.
