# Единая страница ИИ-агентов

Страница объединена по назначениям: голосовой ввод, задачи из сообщений,
телефонные разговоры и обработка текста. Слева — назначение и фактически выбранный
агент; справа — настройки и проверка. Для телефонии есть самостоятельная вкладка
обработки с прежними отдельными разрешениями новых звонков и ночного архива.

Телефонный агент сохраняет отдельный ID, профиль, версии, API и контейнер.
Обычные агенты сохраняют свои назначения и основной вариант на каждую задачу.
Сохранённые настройки не выдаются за подтверждение реального распознавания.
Отсутствие ключа показывается как необходимость подключить модель.

Несохранённый телефонный текст остаётся в форме при переходах; переход между
обычными агентами/назначениями требует подтверждения отмены правок. Обновление
состояния архива не сбрасывает несохранённый флажок новых звонков и не меняет
его исходную ожидаемую версию. Сохранение и тест блокируют дубли; поздние ответы
старой организации не заполняют новый редактор. Общая перезагрузка настроек
сохраняет выбранный раздел и редактируемый вариант.

Проверка обычного агента явно использует текущий черновик; телефонный тест —
точную сохранённую версию. Открытие страницы и навигация не отправляют платные
POST. Кнопка реальной проверки звонка ведёт в чаты, где есть прежнее явное
«Расшифровать и описать». Аудиозвонок из этого интерфейса не инициируется.

Модель очереди, расписание 00:00–08:00 Moscow, интервал 120 секунд, резерв бюджета,
схема 0032 и серверные правила не изменяются. UI считает начатые задания по
сохранённым фазам и не представляет их как живое число одновременно работающих
запросов. Общего размера архивной выборки нет — процент готовности не придуман.

Проверки: 303 UI-теста прошли без пропусков, включая 14 отдельных сценариев
назначений, черновиков, прав и восстановления после ошибки,
а также полный кабинет с синтетическими API в Chromium на 1440, 1024 и 390 px.
Браузерный сценарий проверяет обе формы, раздельный тест и явный запуск архива,
отсутствие ошибок JS и горизонтального переполнения. Все сетевые обращения
перехватываются; настоящие ИИ, CRM, аудио или клиенты не используются.

Изменены только статические файлы UI, тесты и документация. Проверены хэши всех
защищённых файлов: изменений нет. Обычный выпуск через
`ramessenger-local-build.service`; закреплённые MAX/telephony worker не обновляются.
