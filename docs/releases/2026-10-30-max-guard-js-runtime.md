# Проверка JavaScript в штатном браузере

После исправления изоляции тестов выпуск дошёл до собранного образа и
контейнерной проверки. Из 128 тестов один завершился ошибкой: тест
`test_post_script_actually_aborts_a_stalled_fetch` вызывал внешний `node`,
который не является зависимостью рабочего Python-образа.

Проверка теперь выполняет тот же JavaScript отправки в Chromium из
Playwright, уже установленном в рабочем образе. Сетевой fetch подменён
синтетическим зависшим Promise, который завершается только по AbortSignal.
Проверяются именно реальный AbortController и рабочий JS, а не строка с
названием timeout. Независимый предел тестового ожидания исключает бесконечное
зависание; при успехе отправки или отсутствии abort тест завершается ошибкой.

Тест не пропускается и не отключается. Node, новые пакеты и изменения
Dockerfile не добавляются. Код MAX, схема БД и runner не меняются.

Сервер намеренно выполняет тесты из закреплённого внешнего bundle, поэтому
обычный допуск нового коммита не заменит старый Node-тест. Нужна явная установка
новой policy с проверенными SHA-256 и `--previous-policy` текущего bundle.
Затем штатный service выполнит все обязательные тесты перед заменой API.
Эталон кода MAX остаётся прежним, меняются закреплённые тесты и их хэши.
