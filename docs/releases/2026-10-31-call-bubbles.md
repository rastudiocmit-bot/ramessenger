# Звонки в стиле сообщений

Входящий звонок расположен слева, исходящий — справа. Бабл использует обычные
радиусы 16/6 px, шрифт, отступы и тень сообщений; фон обоих направлений слегка
голубой с отдельным читаемым вариантом тёмной темы. В шапке остаются значок
телефона и направление, ниже — имя из текущей карточки клиента, время в часовом
поясе организации и продолжительность разговора. Номер не добавляется в метаданные
бабла. Неизвестная длительность и звонок без разговора обозначены явно; часы
длительного разговора не теряются.

Два круглых значка имеют видимый диаметр 28 px и увеличенную область нажатия:
прослушивание и полный текст. У входящего они справа вверху, у исходящего слева.
Аудио загружается по нажатию через прежний авторизованный маршрут; одновременно
играет одна запись. Полный текст открывается в диалоге с пагинацией, исходными
каналами и временными метками. Закрытие диалога не прерывает аудио.

На главной поверхности показаны четыре строки настоящей сохранённой расшифровки,
а не краткое описание ИИ. Первые страницы читаются автоматически из локального
API, не более двух запросов одновременно на представление. Это GET уже сохранённых
данных: ни запрос Новофону, ни запуск платного распознавания при открытии чата
не выполняется. Последующие страницы читаются по кнопке внутри полного текста.
Кэш разделён по разговору, звонку, запуску, организации и действующему scope
карточки. Завершённый результат переиспользуется; частичный перечитывается при
завершении или очередном обновлении истории. Старые ответы после смены scope
отбрасываются, при потере доступа полный текст закрывается.

До появления текста показано реальное состояние очереди, ночного ожидания,
бюджета либо отсутствие подготовленной расшифровки. Готовый текст появляется
без обновления страницы. Под него заранее оставлена одинаковая высота, поэтому
смена статуса на текст не перемещает последующие сообщения. Аудиоэлемент и
открытый текст сохраняются при обновлении состояния ИИ. Краткое описание,
сотрудники из журнала, исправление описания и явные платные команды сохранены
в «Подробнее о звонке»; подтверждение возможного расхода при повторе обязательно.

Имя из карточки обозначает текущего связанного клиента, а не подтверждённую
личность говорящего на записи. Без имени отображается «Абонент не определён».
Для исходящего имя клиента подписано «Кому». Список сотрудников провайдера не
содержит достоверного признака единственного инициатора: произвольный первый
сотрудник не назначается звонящим. Историческая принадлежность изменившегося
номера остаётся ограничением существующего серверного сопоставления.

Выпуск меняет только UI, тесты и документацию. Защищённые файлы, схема,
расписание архива 00:00–08:00 Moscow, интервал 120 секунд и закреплённые образы
MAX/телефонии не изменены. Выпуск выполняется существующим
`ramessenger-local-build.service`, обновляется только API.

Проверки: 18 сценариев звонков (включая доступ, поздние ответы, локальную
параллельность, пагинацию, частичный ASR, явный повтор с расходом), полный набор
312 UI-тестов без пропусков. Chromium 153 проверяет полный кабинет на 1440,
1024 и 390 px: направления, углы кнопок, четыре строки, отсутствие переполнения,
нулевое изменение высоты при появлении текста, аудио без автозапуска, полный
текст во время воспроизведения и остановку предыдущей записи. Проверены светлая
и тёмная темы. Все сетевые ответы синтетические; реальная расшифровка и доставка
на VPS этими проверками не подтверждаются.
